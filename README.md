# E-Commerce Sales Analysis

## Project Overview
An end-to-end E-Commerce Sales Analysis project using Python and MySQL to clean, process, and analyze approximately 1 million sales records.

The project focuses on identifying sales trends, customer purchasing behavior, delivery performance, product category performance, and customer retention.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- MySQL

## Project Workflow

### 1. Data Cleaning – Python
- Loaded and explored the dataset using Pandas.
- Checked missing values and duplicate records.
- Analyzed numerical and categorical columns.
- Applied the IQR method to identify and remove outliers.
- Visualized original and cleaned data distributions.

### 2. SQL Analysis – MySQL
Performed business analysis to identify:
- Sales and monthly revenue trends.
- Top-performing product categories.
- Average order value.
- Customer purchasing frequency.
- Repeat customer and retention patterns.
- Delivery delays and return rates.
- Shipping performance across locations.
- Customer ratings and payment preferences.

## Dataset
The original dataset contains approximately 1 million records. The full dataset is not included in this repository due to its size.

## Key Learning Outcomes
- Practical experience in data cleaning and preprocessing.
- Writing SQL queries using GROUP BY, CTEs, subqueries, and window functions.
- Analyzing customer behavior and business performance.
- Converting raw data into meaningful business insights.
